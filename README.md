# NetSpectre

> Professional Network Reconnaissance Framework built with Python & Go.

# Installation

Clone the repository:

git clone <url>
cd NetSpectre

**#Requide**
pip install -r requirements.txt

**#Scanner Permisson**

chmod +x ./engine/scanner


## About

NetSpectre is a fast and modular command-line network reconnaissance framework inspired by modern security assessment tools.

It is designed to perform network discovery, port scanning, service detection, and information gathering through a clean and extensible architecture.

---

## Features

- Host Discovery
- TCP Port Scanning
- UDP Port Scanning
- Service Detection
- Banner Grabbing
- DNS Lookup
- WHOIS Lookup
- HTTP Header Analysis
- SSL Certificate Inspection
- Robots.txt Enumeration
- Technology Detection
- JSON Reports
- HTML Reports
- Multi-threaded Scanning (Go Engine)
